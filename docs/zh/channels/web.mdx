Web 控制台是 容大AI 的默认通道，启动后会自动运行，通过浏览器即可与 Agent 对话，并支持在线管理模型、技能、记忆、通道等配置。

## 配置

```json
{
  "channel_type": "web",
  "web_host": "0.0.0.0",
  "web_port": 9899,
  "web_password": "",
  "enable_thinking": false
}
```

| 参数 | 说明 | 默认值 |
| --- | --- | --- |
| `channel_type` | 设为 `web` | `web` |
| `web_host` | Web 服务监听地址，默认监听 `127.0.0.1`（仅本机），如需公网访问请改为 `0.0.0.0` 并设置密码 | `""` |
| `web_port` | Web 服务监听端口 | `9899` |
| `web_password` | 访问密码，留空表示不启用密码保护；监听 `0.0.0.0` 时建议设置 | `""` |
| `web_session_expire_days` | 登录会话有效天数 | `30` |
| `web_file_serve_root` | web 端可直接读取/发送的文件根目录，默认仅限用户主目录及 agent 工作空间；设为 `/` 可放开整个文件系统 | `"~"` |
| `enable_thinking` | 是否启用深度思考模式 | `false` |

配置密码后，访问控制台时需先输入密码完成登录。登录状态默认保持 30 天，期间重启服务也无需重新登录。密码也支持在控制台的「配置」页面中在线修改。

### 实例品牌设置

Web 控制台可以展示你自己的品牌：品牌名称、Logo 简述、自定义 Logo（以及派生出的浏览器 favicon）。品牌是「实例级」的（单个 Web 部署），不影响桌面客户端与文档站。

登录后进入「系统设置 → 品牌设置」即可编辑、保存，无需额外开启功能。旧配置中的 `branding_enabled` 不再生效。

- **范围**：实例级。品牌数据存放于 `<data_root>/branding/`；不会写入 `config.json`。
- **密码前置**：由于 Logo 会开放给未登录访问者，只有配置了 `web_password` 才允许编辑。未配置密码时设置页为只读并说明原因。
- **身份模式**：当前写入仅支持 `identity_mode=legacy` 的单实例模式。数据库身份及其他模式在真实平台授权与审计接入前禁止保存和恢复，旧共享密码不能绕过此限制。
- **接口认证**：品牌写接口接受有效的 Authorization Bearer 或登录 Cookie，不接受仅 URL token。Cookie 客户端先读取 `/api/branding` 返回的 `csrf_token`，保存及恢复时通过 `X-Branding-CSRF` 请求头回传，并保持请求同源；页面会自动处理。
- **损坏恢复**：主配置损坏或丢失时仅展示恢复预览，禁止普通编辑。管理员可重试读取，或确认「恢复全部默认」；损坏原件保存在 `branding/corrupt/`，恢复分配新版本，不复用旧草稿版本。请保留品牌目录中的 `.revision.json` 版本记录。
- **字段/格式限制**：品牌名称 `1–32` 字符，Logo 简述 `0–100` 字符（单行，不含控制字符），图片 `PNG / JPG / WebP`，`≤ 2 MiB`，宽高 `32–4096` px，总像素 `≤ 16,000,000`，不支持动画图片。上传图片会规范化（应用 EXIF、去除元数据）为安全 PNG，并派生 `32×32` favicon。
- **发布模型**：保存或「恢复全部默认」都会原子发布一个新版本；来自其他标签页/浏览器的并发编辑会被检测并提示冲突，而不是静默覆盖。
- **恢复默认**：「恢复全部默认」在确认后把名称、描述、Logo 与 favicon 重置为内置默认，并递增版本号。
- **备份/回滚**：`cow backup` 会打包当前已发布的品牌快照及其引用图片；`cow restore` 以新版本号重新发布到目标数据根目录。不含品牌段的备份不会删除已有品牌——全新实例回退到内置默认。回滚旧版应用前请先备份品牌目录；旧代码不会消费新增的品牌数据。

<Note>
  登录页与侧栏展示的 Logo 是公开资源，请只放置你愿意展示给未登录访问者的内容。
</Note>

## 访问地址

启动项目后访问：

- 本地运行：`http://localhost:9899`
- 服务器运行：`http://<server-ip>:9899`

<Note>
  请确保服务器防火墙和安全组已放行对应端口。
</Note>

## 功能介绍

### 账号菜单

使用个人账号（身份模式 `database`）登录后，侧栏左下角的卡片显示头像、显示名（或用户名）和 `@用户名`，滚动导航时保持常驻，切换租户后仍为同一账号身份。

点击卡片向上展开六个入口的菜单，各项均无需离开当前页面：

- **个人资料**：只读抽屉展示姓名、登录账号、平台身份标识，以及当前租户的成员姓名、实际角色、部门和岗位。全局账号与租户成员资料分开显示，成员姓名不覆盖账号卡片；空值显示「未设置」，无租户显示「未加入任何租户」。读取失败时提供重试，同时保留已确认的登录与改密/退出入口。
- **修改密码**：弹窗填写原密码、新密码、确认密码。成功后撤销会话并要求重新登录，并提示其他已登录会话也会失效。若账号被标记为需改密（首次登录/临时密码），会以同一表单在租户选择与业务数据加载前作为门禁展示，只能完成改密或退出。
- **界面偏好**：浅色/深色、简体/繁体/英文，仅在当前浏览器本地生效，并与顶部选择同步。个人偏好不会写入实例默认；浏览器存储不可用时仅本页生效并提示。
- **切换租户**：仅列出本人有有效成员关系的租户并标记当前项。零租户提示「未加入任何租户」，单租户显示当前名称，多租户可选。切换通过重新加载页面生效，只有新页面验证目标有效后才提交选择；取消时旧页面保持不变，失效目标不会静默进入其他租户。
- **关于当前品牌**：展示当前品牌与版本，并可打开原更新记录链接。
- **退出登录**：结束当前登录会话并回到登录页，保留单次提交与失败重试。

按 Esc 或点击外部关闭菜单；抽屉/弹窗关闭后会恢复焦点到卡片触发入口。移动端与短视口下各项仍可达，隐藏菜单不获焦点。

使用 legacy 访问时，卡片显示「本地访问」：

- **密码保护**：可在菜单中退出登录，适用「界面偏好 / 关于 / 退出」。
- **免登录**：保留「界面偏好 / 关于」，无退出操作，也没有个人改密入口。

若初始登录检查失败，可在登录页选择「重新检查」；若控制台内账号信息不可用，打开卡片选择「重新检查」，当前页面与草稿会保留。确认登录但无法展示资料时，「退出登录」仍可用；显示「退出未确认」时可用「重试退出」或「重新检查」恢复。

### 对话界面

支持流式输出，可实时展示 Agent 的思考过程（Reasoning）和工具调用过程（Tool Calls），更直观地观察 Agent 的决策过程。深度思考功能可通过配置或控制台的「Agent 配置」开关控制。

#### 多会话管理

对话界面支持多会话（Session）管理，所有会话记录持久化存储在数据库中：

- **会话列表**：在「工作台 → 历史会话」页面查看所有可访问的历史会话，支持滚动加载全部记录，并按项目/时间分组管理
- **搜索会话**：在列表上方输入会话标题关键词，搜索范围覆盖全部可访问历史，包含尚未加载的会话。支持中文、英文，英文字母不区分大小写；清空搜索框即可恢复完整列表
- **AI 生成标题**：新会话在首轮对话完成后，自动调用模型生成简短的会话摘要标题
- **新建会话**：点击历史会话页顶部的「新对话」按钮或聊天输入区的 `+` 按钮创建新会话
- **会话操作**：点击会话项右侧的「⋯」按钮，可置顶或取消置顶、重命名、删除会话；删除需确认，确认后永久删除该会话及其所有消息
- **清除上下文**：点击输入区的清除按钮，在当前会话中插入一条分隔线，分隔线以上的消息仍然展示但不再作为模型的上下文输入
- **工作空间 / 模型**：在输入框下方可为当前会话单独设置项目工作空间与模型；使用多个项目时，历史会话会自动按项目分组。详见 [项目架构 - 项目工作空间](/zh/intro/architecture#project-workspace)

#### 权限模式

Agent 能触及的文件与命令范围由权限模式决定：只读（read-only）、工作空间可写（workspace-write）、完全访问（full-access）。单租户安装在「控制台 → 安全设置」中选择全局默认权限，新会话继承该默认值；多租户（数据库模式）下该设置只读，实际能执行什么由调用者的**角色资源授权**决定——某个角色能用哪些工具、哪些资源由管理员分配，会话内不提供放宽权限的入口。工具被拦截时控制台仍会说明原因，但不再提供就地调整权限的按钮。

#### 智能体

「智能体」分为两个入口：**管理 → 智能体配置**（管理模式）与 **工作台 → 智能体**（使用模式）。

- **工作台 → 智能体（使用页）**：以卡片形式只读展示**已保存且启用**的智能体，标明默认项与各自的 `开始对话` 按钮。点击卡片即为所选智能体开启一个新聊天：进入后展示该智能体的名称与头像、聚焦输入框，并绑定其默认工作空间，不会继承其它项目/会话的设置。仅当智能体当前可运行时才会显示可用入口；`view=workbench` 读取为白名单投影，不暴露工作空间、通道实例、核心文件等管理数据。
