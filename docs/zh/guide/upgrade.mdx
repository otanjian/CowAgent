## 命令升级（推荐）

使用 `cow update` 一键完成代码更新和服务重启：

```bash
cow update
```

该命令会自动完成以下流程：

1. 拉取最新代码（`git pull`）
2. 停止当前服务
3. 更新 Python 依赖
4. 重新安装 CLI
5. 启动服务

<Note>
  如果未安装 Cow CLI，也可以使用 `./run.sh update` 完成相同操作。
</Note>

## 手动升级

在项目根目录下执行：

```bash
git pull
pip3 install -r requirements.txt
pip3 install -e .
```

更新完成后重启服务：

```bash
# 使用 Cow CLI (推荐)
cow restart

# 或使用 run.sh
./run.sh restart

# 或使用 nohup 直接运行
kill $(ps -ef | grep app.py | grep -v grep | awk '{print $2}')
nohup python3 app.py & tail -f nohup.out
```

## Docker 升级

在 `docker-compose.yml` 所在目录下执行：

```bash
sudo docker compose pull
sudo docker compose up -d
```

<Tip>
  升级前建议备份 `config.json` 配置文件。Docker 环境下如需保留数据，可通过 volume 挂载持久化工作空间目录。
</Tip>

## 上游项目 客户端升级

[上游项目 桌面客户端](/zh/guide/desktop)内置自动更新能力，有新版本时会自动检查并提示，一键即可下载并重启完成升级。

可以前往[上游客户端下载页](https://www.rsm.global/china/zh-hans)获取其公开发行版。这些公开更新不包含本仓库的容大AI品牌和改动。
