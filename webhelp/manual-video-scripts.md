# 产品使用手册 · 录屏脚本

手册页面（`webhelp/manual.php`）上每个视频条目都在这里有对应的一份脚本。本文件是仓库内部的录制材料，不参与站点渲染、也不从任何页面链接出去；它与手册内容放在一起，改手册时不易漏掉脚本。演示一律用测试账号与假数据。页面上的「内容要点」是给读者看的事前概览；这里写的是**开拍前准备什么、镜头按什么顺序走、旁白说什么**。

## 怎么用

- 小节标题 `### \`<主题>.<视频>\` · 标题 · 时长` 里的标识与 `includes/content.php` 的 `manual_topics` 一一对应，改手册结构后跑 `php tools/check-manual.php`，脚本缺条、多条或标题/时长与结构不一致都会报错。
- 录完之后在 `content.php` 的对应条目补 `src`（可选 `poster`），页面即由占位切换为播放器，不用改模板：

  ```php
  ['id' => 'login', 'duration' => '2:40',
   'src' => 'assets/video/manual-start-login.mp4',
   'poster' => 'assets/video/manual-start-login.jpg'],
  ```

- 每份脚本四段：**开拍前准备**（账号与前置数据）、**操作序列**（镜头动作）、**旁白**（可照念）、**录制注意**（时效、脱敏、易踩的坑）。
- 旁白的口径与手册、能力文档一致；**不要在录制现场临时改说法**，有疑问先改文档。
- 演示数据一律用测试租户与测试账号，画面里不出现真实密码、真实凭据与真实客户数据。

## 工作台（日常使用）

### `start.login` · 登录控制台与首次改密 · 2:40

**开拍前准备**：一个从未登录过、持有效临时密码的测试账号；一个已改密的正常账号；一个租户管理员账号。

**操作序列**

1. 打开登录页，输入账号与临时密码，提交后落在强制改密页。
2. 停在受限会话上，逐个点一下导航里其它入口，都被拦回；指出此时可做的只有查看自身信息、改密与退出。
3. 按提示设置新密码，进入工作台首页。
4. 切到租户管理员视角，在「成员管理」里对该成员执行「重置密码」，把新生成的一次性临时密码展示给镜头（用假数据）。

**旁白**

- 「首次登录拿到的是管理员发的临时密码，有期限，默认 24 小时。」
- 「改密之前是受限会话：只能看最小范围的自身信息、改密和退出，管理员身份也不豁免。」
- 「改密成功后，其它已登录的会话会失效，需要重新登录。」

**录制注意**

- 不要拍到真实密码；临时密码的时效是默认值，画面里用示意数据。
- 顺手带一句：登录失败到阈值会返回 429 并提示稍后重试；「账号不存在」与「密码错误」返回同样的提示，不会暴露账号是否存在。

### `start.navigate` · 界面导览：两个导航区域 · 3:20

**开拍前准备**：一个同时具备工作台与管理控制台权限的账号。

**操作序列**

1. 从工作台侧栏逐个点过去，念出六个页面的名字：对话、智能体、我的待办、定时任务、知识库、场景应用。
2. 从侧栏顶部切到管理控制台，按四组走一遍：智能体开发（智能体管理、工具与技能、记忆管理）、模型与接入（模型服务、消息渠道）、组织与权限（成员管理、组织架构、角色权限）、平台运维（租户管理、系统设置、品牌设置、运行日志、审计），并带一下顶部的控制台概览。
3. 再切回工作台，指出切换入口的位置。
4. 展开侧栏底部的账号菜单，念一遍里面的动作：看身份、切租户、改密码、个人偏好、退出。

**旁白**

- 「工作台是日常使用的地方，管理控制台是配置和治理的地方，两边侧栏顶部互相切换。」
- 「你看到哪些菜单由服务端授权决定：只展示你获准读取且已开放的页面，空分组不显示。」
- 「隐藏菜单不是鉴权——每个请求都会在服务端重新校验权限。」

**录制注意**

- 用两个不同权限的账号各录一小段对比，能把「看不到 = 没授权」讲清楚。
- 管理控制台里没有可访问页面时该入口不出现，这点值得一个特写。

### `chat.new` · 新建对话与选择智能体 · 2:30

**开拍前准备**：至少三个可用的智能体，其中一个不可用（用于演示拦截提示）。

**操作序列**

1. 在侧栏点「新建对话」；再进「历史对话」页点一次「新对话」，说明两个入口等价。
2. 点「新对话」旁的下拉箭头，展开可用智能体菜单，点其中一个开始会话。
3. 回到同一个菜单，选「多智能体对话」，勾选两个智能体，点「开始对话」，指出第一个是默认智能体。
4. 换到工作台「智能体」页，在卡片上点「开始对话」，说明这是第三个入口。
5. 在输入框「描述你的任务，或直接提问…」写下一条真实任务，回车发送。

**旁白**

- 「勾选的第一个智能体是本次会话的默认智能体，负责接收消息，也可以把任务委派给其他成员。」
- 「智能体不可用时，「开始对话」会被拦住并说明原因——比如当前版本尚未开放对话，或暂无对话权限。」

**录制注意**

- 多智能体对话的默认成员规则容易讲漏，务必配一个镜头指出勾选顺序。
- 输入的任务示例要具体，不要用「test」这类占位词。

### `chat.compose` · 输入区控件逐个认识 · 3:10

**开拍前准备**：一个能跑较长任务的智能体；已配置多个模型。

**操作序列**

1. 发一条会持续一会儿的任务，任务运行中把发送按钮变成「中止」的瞬间拍清楚，点一下中止。
2. 打开「本次会话模型」，依次展示「跟随全局设置」「跟随智能体默认模型」与指定某个模型。
3. 用一句口语化的需求演示「智能优化输入」，对比优化前后的指令。
4. 点麦克风演示「语音输入」：录一句，再点一次结束并转写，直接发送。
5. 演示「清除上下文」，说明这会从干净的上下文继续。
6. 任务运行中点「引导当前任务」，补充一句指令，指出不必中止重来。
7. 在输入框敲 `/` 弹出命令菜单，点 `/status` 看运行状态、点 `/context` 看上下文、点 `/skill list` 看已安装技能、点 `/knowledge` 看知识库统计；再敲 `@` 引用一个智能体或一个文件。

**旁白**

- 「需要压上下文长度时，可以发 /compact 压缩较早的对话，或用 /clear 清空上下文。」
- 「@ 可以把智能体或文件直接带进当前提问。」
- 「完整的命令清单在手册的「命令速查」主题里。」

**录制注意**

- 这条视频信息量大，建议按「发送区 → 模型 → 输入辅助 → 上下文 → 命令与引用」分小节，每节给一个小标题字幕。
- 语音输入需要麦克风权限，提前授权好，不要在现场弹权限框。

### `chat.attach` · 上传文件与文件夹 · 2:20

**开拍前准备**：一个含 5–8 个文件的测试文件夹；几张图片；一个 zip 包。

**操作序列**

1. 点输入框的附件按钮，分别走一遍「上传文件」与「上传文件夹」。
2. 换一种方式：把文件直接拖进对话框，再粘贴一张图片。
3. 停在输入框上方，指出附件已挂上、会随下一条消息一起提交。
4. 发出去以后，打开右侧工作空间面板，切「预览」与「文件」两个页签，演示编辑、保存、下载、复制路径、在新标签页打开。
5. 快速带一遍支持的类型：图片、PDF / Word / Excel / PPT、文本与代码、zip / rar / 7z。

**旁白**

- 「附件要随消息一起提交才有意义——确认它挂在输入框上方，再发这条消息。」
- 「上传的文件夹会作为一个整体保存在工作空间里，助理可以批量处理里面的文件。」

**录制注意**

- 最容易踩的坑是「选了文件但没随消息提交」，这正是使用者报「助理看不到文件」的原因，要拍清楚。

### `todo.task` · 定时任务 · 3:00

**开拍前准备**：至少一个已配置调度与动作的任务；一个配置了通道的环境（用于「立即执行」的确认框）。

**操作序列**

**旁白**

- 「定时任务由助理在对话中创建并归属到对应智能体；这个页面用于查看、编辑、执行与启停。」
- 「编辑已有任务时通道类型不可更改。」

**录制注意**

- 「本页没有新增入口」是使用者最常问的点，要给侧栏和按钮区一个明确的空镜。

### `agents-admin.create` · 创建一个智能体 · 3:20

### `agents-admin.capability` · 配置：能力与核心文件 · 3:10

**开拍前准备**：一个已安装多个技能与工具的智能体；一个已有归属定时任务的智能体。

**操作序列**

1. 切到「能力」页签，在「使用全部已安装技能」与「只启用勾选的技能」之间切换，指出数量变化。

### `troubleshoot.issues` · 常见问题排查演示 · 4:30

**开拍前准备**：能复现以下现象的测试环境——首次登录、无权限智能体、未提交的附件、未同步的知识库、未启用的渠道、被限流的登录。

**操作序列**

逐个复现并给出处理路径：

1. 登录后只看到修改密码的页面 → 说明这是强制改密受限会话，改密即恢复。
2. 「开始对话」不可用 → 读出页面给出的原因，联系管理员。
3. 上传了文件助理看不到 → 回到输入框，指出附件必须随消息提交。
4. 知识库看不到刚加的文档 → 检查顶部选择的智能体与分类筛选。
5. 渠道配好了收不到消息 → 检查实例是否已启用、是否绑定了可用智能体。
6. 忘记密码 → 走一遍管理员「重置密码」。
7. 登录被限流 → 展示 429 的提示，说明稍后重试与提示不区分账号是否存在。
8. 接口返回 401 / 403 / 503 → 分别说明：缺有效会话、不具备资格、身份库不可用；指出资源不可见时返回 404 而不是 403。

- 「这些现象的具体原因，可以在手册的这个主题下方对照速查表。」

**录制注意**

- 这条最长，建议按现象分段并加章节字幕；第 8 点可以只做讲解、不必现场构造请求。
