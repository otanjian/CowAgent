# 智能生产排产技能 (Intelligent Production Scheduling)

面向工厂 PMC（生产计划控制）岗位的智能排产工具。基于**约束满足 + 启发式搜索（禁忌搜索/模拟退火）**的有限能力排程算法，支持多工序路线、设备资源约束、物料齐套检查、人力班组约束、换线时间、设备维护窗口等真实工厂场景。

## 功能概述

1. **多工序路线排程** - 支持复杂工艺路线（注塑→CNC→装配→检测）
2. **设备资源约束** - 考虑设备日产能、可用时段、维护计划、换线时间
3. **物料齐套检查** - 自动检查库存与在途物料是否满足生产需求
4. **人力班组约束** - 考虑班组人数、技能矩阵、排班计划
5. **换线时间管理** - 区分同产品换模（15分钟）与不同产品换线（60分钟）
6. **启发式搜索优化** - 禁忌搜索/模拟退火算法，支持多目标优化
7. **甘特图可视化** - 交互式HTML甘特图（D3.js）
8. **物料需求计划** - 输出采购/领料建议
9. **瓶颈分析** - 识别产能瓶颈设备
10. **急单插单分析** - What-If分析，评估急单对现有排程的影响
11. **历史记录管理** - 排产结果持久化存储，支持查看和对比

## 排产参数配置

| 参数 | 选项 | 默认值 |
|------|------|--------|
| 排产模式 | 正向排产 / 逆向排产 | 正向排产 |
| 优化目标 | 最小化延期 / 最小化总工期 / 最小化成本 / 平衡模式 | 最小化延期 |
| 迭代次数 | 100-5000 | 500 |

## 排产算法

### 启发式搜索优化

采用**禁忌搜索（Tabu Search）+ 模拟退火（Simulated Annealing）**混合算法：

1. **初始解生成** - 按优先级+EDD（最早交期优先）排序生成初始可行解
2. **邻域搜索** - 通过交换工单顺序生成邻域解
3. **禁忌表** - 避免重复访问近期搜索过的解
4. **评估函数** - 综合考虑延期惩罚、换线时间、设备负载不平衡度
5. **多目标优化** - 支持交期优先、产能平衡、成本最优等目标

### 约束处理

- **设备独占约束** - 同一设备同一时间只能加工一个工单
- **工序先后约束** - 前道工序完成后才能开始下一道
- **物料齐套约束** - 物料到位后才能开工
- **班组约束** - 考虑班组可用性和技能匹配
- **维护窗口** - 避开设备维护时间段
- **换线时间** - 同产品换模15分钟，不同产品换线60分钟

## 排程执行（优先使用脚本模板）

**重要：AI执行排程时，禁止从零编写 Python 脚本。必须基于技能包内置模板修改。**

### 模板文件位置

- **排程算法模板**：`skills/pmc-scheduler/scripts/schedule_template.py`
- **甘特图模板**：`skills/pmc-scheduler/assets/gantt_template.html`

### 排程算法模板（schedule_template.py）已包含

- 统一的输入数据结构解析（兼容中英文键名）
- 班次/工作时段对齐逻辑（白班 08:00-17:00 / 夜班 20:00-05:00 / 两班倒 08:00-22:00+23:00-03:00）
- 设备独占 + 工序依赖 + 换线时间约束
- 禁忌搜索优化（按优先级+EDD初始解，自动迭代优化）
- 物料需求计划（结合库存、在途、提前期计算缺口）
- **所有 datetime 对象在 JSON 输出前强制转为 ISO 字符串**
- 标准输出文件：`tmp/schedule_result.json`、`tmp/schedule_summary.json`

### AI执行步骤

1. 读取用户上传的 JSON 数据文件（如 `tmp/scheduling_data.json`）
2. **直接复制 `skills/pmc-scheduler/scripts/schedule_template.py` 到 `tmp/pmc_schedule.py`**
3. 在复制的脚本中修改 `INPUT_FILE` 指向实际数据文件，运行脚本
4. 脚本自动输出：
   - `tmp/schedule_result.json` — 完整排程结果
   - `tmp/schedule_summary.json` — 摘要
   - `tmp/schedule_gantt.html` — **双视图甘特图（已内置HTML生成，无需额外处理）**
5. 返回排产摘要、物料预警和 HTML 文件路径

**注意：脚本模板已内置 `generate_gantt_html()` 函数，会自动加载 `assets/gantt_template.html` 生成HTML。AI不要自己写HTML生成逻辑。**

### 关键约定（减少错误）

- **禁止自己从零写排程算法和班次逻辑**，直接复用模板中的 `dispatch_orders()` / `optimize_schedule()` / `calculate_material_plan()`
- 日期解析使用 `_parse_date()`，支持 `%Y-%m-%d` 和 `%Y-%m-%d %H:%M`
- 所有输出到 JSON 的数据必须经过 `serialize_for_json()` 或 `_to_iso()` 处理
- 排程结果中的 `start_time`/`end_time` 在生成 JSON 输出时必须转为字符串
- **甘特图 D3.js X轴（日期轴）必须使用 `d3.axisTop()` 放在顶部，禁止用 `d3.axisBottom()` 放在底部**
- HTML 生成优先使用技能包模板 `assets/gantt_template.html`，替换模板变量即可

## 使用场景

### 场景一：常规排产
用户输入工单数据，系统执行标准排产流程，输出甘特图和排产明细。

### 场景二：急单插单分析
用户提出插入急单，系统对比插单前后的排程变化，评估影响范围。

### 场景三：瓶颈分析
用户请求分析当前排程的瓶颈设备，系统输出设备负载和优化建议。

### 场景四：物料齐套检查
用户上传工单和物料数据，系统检查哪些工单可以立即开工，哪些缺料。

### 场景五：历史记录对比
用户查看历史排产记录，对比不同方案的差异。

## 注意事项

1. 物料数据必须准确，否则齐套分析结果不可靠
2. 工序配置不完整时，系统使用默认参数（单工序、通用设备）
3. 排产结果仅供参考，实际执行需结合车间情况调整
4. 甘特图中红色标记表示延期，橙色表示物料缺口
5. 迭代次数越多，优化效果越好，但计算时间越长
6. 建议正向排产用于评估产能，逆向排产用于确保交期

## 技术架构

- **前端**：Web工作台（HTML + Tailwind CSS + JavaScript）
- **后端**：Python Web API（web.py）
- **算法引擎**：AdvancedScheduler（禁忌搜索 + 模拟退火）
- **甘特图**：D3.js 交互式可视化
- **数据持久化**：JSON文件存储（支持历史记录管理）
- **ERP对接**：预留RESTful API接口（U9/SAP/金蝶）
