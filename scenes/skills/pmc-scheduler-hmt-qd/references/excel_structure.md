# Excel结构详细说明

## Sheet: 排产规则

| 列 | 内容 |
|----|------|
| A列 | 规则序号(1-10) |
| B列 | 规则文本 |

## Sheet: 产能

| 列 | 内容 | 示例 |
|----|------|------|
| A | SAP物料号 | 8000004406 |
| B | 课别 | 二课 |
| C | 产线 | S0302 |
| D | 产能(每天) | 2050 |
| E | 优先级 | 1 |

注意：优先级3及以上的产线不排产（如4406的S2303优先级3被跳过）

## Sheet: 排产1

| 列号 | 列字母 | 内容 | 示例 |
|------|--------|------|------|
| 2 | B | SAP物料号 | 8000004406 |
| 7 | G | 备货产品 | "2周"/"3周"/"7月份4周量的提前备出" |
| 15 | O | 备注 | "控制库存"/"预计设变"/"提前备货2周" |
| 27 | AA | 预估减出货量减库存量 | 动态识别 |
| 28 | AB | 生产线量 | 动态识别 |
| 29 | AC | 差异量减排产量（库存量） | 负数=有库存，正数=缺货 |
| 52 | AZ | 第一周出货量 | 20000 |
| ... | ... | ... | ... |
| 87 | CI | 最后一周出货量 | |

### 库存列说明
- 库存字段名为「差异量减排产量」，按表头动态识别。
- 当「生产线量」<> #N/A 时：差异量减排产量 = 预估减出货量减库存量 - 生产线量。
- 当「生产线量」= #N/A 时：差异量减排产量 = 预估减出货量减库存量。
- 客户符号约定：负数表示有库存，正数表示缺货。

### 未来出货量列对应（旧模板）
- AZ(52) = 第一周
- BA(53) = 第二周
- BB(54) = 第三周
- BC(55) = 第四周
- 每列覆盖7天（一周）；客户新版按表头日期动态识别（AD~BK）

## Sheet: 班组产线

### 结构
- 每行一个班组人员
- 列包含: 序号、姓名、各产线分配
- 产线名可能带"S"前缀也可能不带

### 匹配逻辑
```python
# 同时匹配带S和不带S前缀
line_name = "S6605"
line_no_s = line_name.replace("S", "")  # "6605"
# 在班组产线表中查找包含"6605"或"S6605"的行
```
