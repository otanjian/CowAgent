# Web Channel

提供了一个默认的AI对话页面，可展示文本、图片等消息交互，支持markdown语法渲染，兼容插件执行。

# 使用说明

 - 在 `config.json` 配置文件中的 `channel_type` 字段填入 `web`
 - 程序运行后将监听9899端口，浏览器访问 http://localhost:9899/chat 即可使用
 - 监听端口可以在配置文件 `web_port` 中自定义
 - 对于Docker运行方式，如果需要外部访问，需要在 `docker-compose.yml` 中通过 ports配置将端口监听映射到宿主机

## 界面外观

点击控制台右上角的调色板按钮打开“外观”，选择后立即生效，关闭面板会保留选择。

- **商务青蓝**：浅灰侧栏、青蓝强调色，是新浏览器的默认方案。
- **深蓝侧栏**：保留深色导航区域，内容区随明暗模式变化。
- **经典配色**：保留黑色侧栏和绿色交互方向；已有浅色/深色偏好的浏览器升级后自动使用此方案。
- 每套配色均可选择浅色、深色或跟随系统。跟随系统会自动响应系统明暗变化。
- “恢复默认”恢复商务青蓝和跟随系统，不改变语言、账号、租户、聊天或品牌设置。

偏好只保存在当前浏览器，同一浏览器中的不同账号共用，不同步到其他设备或实例配置。存储可用时，刷新会恢复选择，同源标签页会同步；若显示“仅本页生效”，当前页仍能切换，但刷新可能恢复之前的设置。

配色覆盖公共导航、顶部栏、对话首页、输入框和外观面板。首页采用单顶栏、左对齐欢迎区、输入框和三条任务建议；选择“商务青蓝 + 浅色”可使用参考图中的浅色风格。经典配色保留原有颜色方向，也使用新的首页布局。其他业务页面沿用原有深浅模式。

侧栏“新建对话”复用原有会话行为，保留输入草稿、附件及其他会话的后台回复。空白首页将输入框放在欢迎语下方，开始对话后回到底部；任务建议只填入可编辑文字，需要点击发送才会执行。配置、智能体配置、技能、记忆、知识和通道可从“资源管理”展开，原有功能入口均保留。顶部侧栏按钮在桌面切换图标列，在手机打开导航抽屉。

账号菜单“界面偏好”与顶部调色板打开同一面板，配色、明暗和本地语言选择同步；关闭不会丢失选择。

### 升级与回退

Web 使用 `cow_theme` 保存 `light`、`dark` 或 `system`，使用 `cow_web_palette` 保存配色；Desktop 的独立主题包与 `cow_theme_id` 不变。

回退到只支持 light/dark 的旧 Web 版本前，请在外观面板中选择经典配色，并显式选择浅色或深色。这样旧版可继续读取明暗偏好，配色键可保留供再次升级使用，无需清空浏览器数据。
