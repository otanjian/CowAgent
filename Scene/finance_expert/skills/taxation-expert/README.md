# 专业税务咨询技能

## 简介

一个专业税务咨询技能，为用户提供权威、规范的税务政策解答服务。

## 功能特点

✅ **权威依据** - 严格依据法律法规、总局规章、官方解读进行解答
✅ **结论先行** - 直接、明确给出税务处理结论
✅ **可追溯** - 每条依据标注来源、文号、发布时间
✅ **双格式输出** - Markdown + Word两种格式
✅ **格式规范** - 专业排版，适合存档汇报

## 触发条件

当您咨询以下内容时，此技能将自动启用：

- 税务问题咨询
- 税务政策解读
- 纳税申报指导
- 税务筹划建议
- 税收优惠申请
- 各类税种处理（增值税、企业所得税、个人所得税等）

## 咨询示例

```
帮我看看小规模纳税人季度销售额30万以内免税的政策依据是什么？
```

```
企业研发费用加计扣除的比例是多少？需要留存备查的资料有哪些？
```

```
个人所得税专项附加扣除的标准是什么？
```

## 回答结构

每次回答都包含以下部分：

1. **核心结论** - 直接给出答案
2. **政策依据** - 逐条列出法规条款
3. **引用出处** - 表格形式标注来源
4. **补充说明** - 复杂问题进一步解释
5. **免责声明** - 明确适用范围

## Word文档

如需生成可编辑的Word文档，请在咨询时说明「请生成Word文档」，系统将自动生成规范格式的 `.docx` 文件供下载。

## 免责声明

本技能提供的税务咨询意见仅供参考，不构成正式税务法律意见。具体执行以主管税务机关最终口径为准。建议在重要税务事项申报前与当地税务机关确认。
