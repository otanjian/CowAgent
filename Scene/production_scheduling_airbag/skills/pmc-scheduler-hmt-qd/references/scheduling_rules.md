# 排产规则详解（10条）

## 规则1：数据定义

排产1表中周出货量列为未来出货量，每列覆盖一周（7天），列范围按表头日期动态识别；库存字段名为「差异量减排产量」，按表头动态识别。

库存列计算规则：
- 当「生产线量」<> #N/A 时：差异量减排产量 = 预估减出货量减库存量 - 生产线量
- 当「生产线量」= #N/A 时：差异量减排产量 = 预估减出货量减库存量

客户符号约定：该值为负表示有库存，为正表示缺货。

## 规则2：需排产量计算

需排产量 = W1 + W2 + 库存（差异量减排产量）。

- 库存为负值：表示有库存，抵扣出货量、减少排产需求
- 库存为正值：表示缺货，需额外补足

示例（客户文件）：
```
物料2797: W1=540, W2=540, 差异量减排产量=-3330
需排产量 = 540+540+(-3330) = -2250 ≤ 0 → 库存充足无需排产
```

## 规则3：排产期间确定

按日期顺序找出前两个出货量不为0的期间：
- 若第二期出货量为0 → 仅取第一期
- 两期均有出货 → 从第一期起始日至8/10共11天全部安排早班

示例：
```
物料4406: W1=20000, W2=20000 → 两期均有 → 7/31~8/10共11天早班
物料4361: W1=2400, W2=0 → 仅取第一期
```

## 规则4：产线选择

在产能表中查找SAP物料对应的产线及优先级：
- 取优先级前2名
- 优先级3及以上不排产
- 单产线物料使用唯一产线

示例：
```
物料4406: S0302(p1,2050), S0601(p2,1950), S2303(p3,1950)
→ 取S0302和S0601，跳过S2303
```

## 规则5：早班填入

匹配排产2表中SAP+课别+产线行，从第一期起始日在早班列逐日填入产能值：
- 剩余需排产量 < 当日产能 → 填入剩余量
- 次日填0表示需求已满足
- 之后不填

## 规则6：夜班触发（基本规则）

11天早班排产总量不足以覆盖第一周出货量时，需安排夜班。

示例：
```
物料4406: 11天早班=(2050+1950)×11=44000 > W1=20000 → 不触发
```

注意：实际排产中所有夜班均由规则9触发，规则6为理论兜底。

## 规则7：设变检查

排产1表备注（O列）含"设变"字样的物料：
- 原则上不安排排产
- **例外**：备货（G列）有明确备货周期且库存不足以覆盖后续出货时，可按备货规则排产

示例：
```
物料4361: O="预计设变", G="3周", W1=2400, W2=0, 库存=-1875
→ W2=0仅取第一期，但设变 → 不排产

物料4362: O="预计设变", G="3周", 库存=-400
→ 设变但库存仅400，备货3周 → 按规则8排产(8/3起早班)
```

## 规则8：备货产品提前排产

排产1表备货（G列）标注备货周期时：
1. 计算现有库存可覆盖的出货周数
2. 当后续出货超出库存覆盖范围时
3. 从缺货前一周的周一开始排产
4. 仅安排早班至排产期末（8/10）

示例：
```
物料3925: G="2周", 库存=-42920, W1=20520, W2=22080, W3=19440
库存42920覆盖W1+W2(42600)后仅剩320
320不足以覆盖W3(19440)
→ 从W2起始日(8/3周一)开始排产
→ S6206早班8天×2150(8/3~8/10)
```

## 规则9：备货产品夜班触发

**触发条件（需同时满足）：**
1. G列含"2周""3周""4周"，或O列含"提前备货2周"
2. 且 (第一周出货量 + 第二周出货量) ÷ 14 > 产线日产能

**注意：**
- 多产线时取产能合计
- G列="3周"也会触发夜班检查（无例外）
- 用 /14（两周日历天数），不是 /10（工作日）

示例：
```
物料4887: O="提前备货2周", W1=21000, W2=21000, 产能=1400+1200=2600
(21000+21000)/14 = 3000 > 2600 → 触发夜班

物料4083: G="2周", W1=21120, W2=15360, 产能=1400+1350=2750
(21120+15360)/14 = 2606 < 2750 → 不触发

物料5268: G="3周", W1=15000, W2=15000, 产能=1400
(15000+15000)/14 = 2143 > 1400 → 触发夜班
```

## 规则10：班组分配

根据排产2表已排产产线（D列），在班组产线表中匹配对应班组人员填入K列：
- 如该班组已安排在其他产线，选择可替代班组

### 匹配注意
- 产线名可能带"S"前缀也可能不带
- 需同时匹配带S和不带S的产线名
