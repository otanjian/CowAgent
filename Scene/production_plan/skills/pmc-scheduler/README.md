# 智能生产排产技能

面向工厂 PMC（生产计划控制）岗位的智能排产工具。基于约束满足 + 启发式搜索（禁忌搜索/模拟退火）的有限能力排程算法，支持多工序路线、设备资源约束、物料齐套检查、人力班组约束、换线时间等真实工厂场景。

## 功能概述

1. **多工序路线排程** - 支持复杂工艺路线（注塑→CNC→装配→检测）
2. **设备资源约束** - 考虑设备日产能、可用时段、维护计划、换线时间
3. **物料齐套检查** - 自动检查库存与在途物料是否满足生产需求
4. **人力班组约束** - 考虑班组人数、技能矩阵、排班计划
5. **换线时间管理** - 区分同产品换模（15分钟）与不同产品换线（60分钟）
6. **启发式搜索优化** - 禁忌搜索/模拟退火算法，支持多目标优化
7. **甘特图可视化** - 交互式HTML甘特图，支持按设备和按订单两种视图
8. **物料需求计划** - 输出采购/领料建议
9. **瓶颈分析** - 识别产能瓶颈设备
10. **急单插单分析** - What-If分析，评估急单对现有排程的影响
11. **历史记录管理** - 排产结果持久化存储，支持查看和对比

## 数据输入方式

### 方式一：JSON数据文件（推荐）

对于工单数量较多的场景，建议将排产数据打包为JSON文件上传。文件包含：工单数据、设备资源、班组信息、物料库存。

```json
{
  "version": "1.0",
  "params": {
    "mode": "forward",
    "objective": "tardiness",
    "iterations": 500
  },
  "orders": [
    {
      "工单号": "WO001",
      "产品名称": "电机壳体",
      "数量": 100,
      "交期": "2026-04-20",
      "优先级": "紧急",
      "工序路线": [...],
      "BOM物料清单": {"原材料A": 2.0, "原材料B": 1.0}
    }
  ],
  "machines": [
    {"machine_id": "M001", "machine_name": "注塑机-1", "capacity_per_day": 500}
  ],
  "teams": [
    {"team_name": "白班A组", "headcount": 12, "shift": "day"}
  ],
  "materials": [
    {"material_name": "原材料A", "stock": 1000, "on_the_way": 500, "lead_time": 3}
  ]
}
```

### 方式二：手动录入（Web工作台）

在Web界面中打开「智能排产工作台」，逐条录入工单信息：

**必填字段：**
- 工单号
- 产品名称
- 数量
- 交期
- 工序路线（JSON格式或简写格式）

**选填字段：**
- 优先级（紧急/高/中/低）
- 设备需求（注塑机/CNC/装配线/通用）
- 换线时间
- BOM物料清单
- 班组需求（白班/夜班/两班倒）
- 备注

**工序路线格式示例：**
```json
[
  {"process_name": "注塑", "time_per_unit": 2, "machine_id": "M001"},
  {"process_name": "CNC加工", "time_per_unit": 5, "machine_id": "M003"},
  {"process_name": "装配", "time_per_unit": 3, "machine_id": "M005"}
]
```

简写格式：
```
注塑:2|CNC加工:5|装配:3
```

## 排产参数配置

| 参数 | 选项 | 默认值 |
|------|------|--------|
| 排产模式 | 正向排产 / 逆向排产 | 正向排产 |
| 优化目标 | 最小化延期 / 最小化总工期 / 最小化成本 / 平衡模式 | 最小化延期 |
| 迭代次数 | 100-5000 | 500 |

## 排产算法

### 启发式搜索优化

采用**禁忌搜索（Tabu Search）+ 模拟退火（Simulated Annealing）**混合算法：

1. **初始解生成** - 按优先级+EDD（最早交期优先）排序生成初始可行解
2. **邻域搜索** - 通过交换工单顺序生成邻域解
3. **禁忌表** - 避免重复访问近期搜索过的解
4. **评估函数** - 综合考虑延期惩罚、换线时间、设备负载不平衡度
5. **多目标优化** - 支持交期优先、产能平衡、成本最优等目标

### 约束处理

- **设备独占约束** - 同一设备同一时间只能加工一个工单
- **工序先后约束** - 前道工序完成后才能开始下一道
- **物料齐套约束** - 物料到位后才能开工
- **班组约束** - 考虑班组可用性和技能匹配
- **维护窗口** - 避开设备维护时间段
- **换线时间** - 同产品换模15分钟，不同产品换线60分钟

### 2. 交互式甘特图（HTML）

**双视图切换：** 甘特图支持「按设备」和「按订单」两种视图，通过顶部按钮切换：

- **按设备视图（D3.js）**：以设备/产线为Y轴，时间轴为X轴，直观展示每台设备上的工单排布。鼠标悬停显示详细信息（工单号、产品、工序、数量、起止时间、时长）。颜色标识：绿色=正常，红色=延期，橙色=缺料。
- **按订单视图（表格）**：以工单为行，展示每个工单在各工序、各设备上的起止时间，便于按订单追踪生产进度。

**物料需求计划表格**：甘特图下方直接展示物料需求汇总，包含需求总量、可用库存、缺口、可用率、建议采购量和建议到货日期。

## 使用场景

### 场景一：常规排产
用户输入工单数据，系统执行标准排产流程，输出甘特图和排产明细。

### 场景二：急单插单分析
用户提出插入急单，系统对比插单前后的排程变化，评估影响范围。

### 场景三：瓶颈分析
用户请求分析当前排程的瓶颈设备，系统输出设备负载和优化建议。

### 场景四：物料齐套检查
用户上传工单和物料数据，系统检查哪些工单可以立即开工，哪些缺料。

### 场景五：历史记录对比
用户查看历史排产记录，对比不同方案的差异。

## 注意事项

1. 物料数据必须准确，否则齐套分析结果不可靠
2. 工序配置不完整时，系统使用默认参数（单工序、通用设备）
3. 排产结果仅供参考，实际执行需结合车间情况调整
4. 甘特图中红色标记表示延期，橙色表示物料缺口
5. 迭代次数越多，优化效果越好，但计算时间越长
6. 建议正向排产用于评估产能，逆向排产用于确保交期

## 技术架构

- **前端**：Web工作台（HTML + Tailwind CSS + JavaScript）
- **后端**：Python Web API（web.py）
- **算法引擎**：禁忌搜索 + 模拟退火
- **甘特图**：D3.js 交互式可视化
- **数据持久化**：JSON文件存储（支持历史记录管理）
- **ERP对接**：预留RESTful API接口（U9/SAP/金蝶）
