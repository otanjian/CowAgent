# tenant-resource-isolation Specification

## Purpose
规定最小身份管理版本的租户资源隔离、个人数据归属和迁移契约，在复用现有 Agent 存储的同时阻止跨租户路径及默认回退，并明确首期未适配运行消费者的关闭边界，避免以管理页面完成代替业务隔离验收。
## Requirements
### Requirement: Agent 租户绑定与现有标识保持稳定

系统 SHALL 保持 Agent ID 全局唯一并为每个可访问 Agent 建立唯一租户绑定；读取 Agent 或业务存储前 SHALL 校验该绑定。租户列表和默认 Agent 选择 SHALL 只在当前租户内进行，无 Agent 时返回空列表。既有业务 session/run ID 和每 Agent 存储 SHALL 保持兼容，未绑定或绑定读取失败时 MUST 拒绝访问而不是使用全局默认 Agent。

#### Scenario: 读取本租户安全概览
- **WHEN** 有权成员请求本租户的 Agent 列表
- **THEN** 仅返回已绑定且获准查看的 Agent 名称等安全字段，不返回 workspace、模型凭据或其他租户记录

#### Scenario: 相同会话标识属于不同 Agent
- **WHEN** 两租户的不同全局 Agent 使用相同业务 session 字符串
- **THEN** 请求仅能访问所选租户合法 Agent 下的记录，不能靠 session 字符串控制另一租户资源

#### Scenario: 缺失或损坏绑定
- **WHEN** 新租户没有 Agent，或绑定/配置读取失败
- **THEN** 无 Agent 时返回空列表，读取失败时拒绝操作，均不选取其他租户或平台默认 Agent

### Requirement: 个人与共享资源有明确边界

系统 SHALL 在租户和 Agent 校验之后继续检查个人资源所有者与功能权限。普通成员只能读取本人会话、执行记录和个人记忆；tenant_admin 可按管理权限读取本租户资源。历史 Agent 资产 SHALL 默认归初始管理员私有，只有明确登记共享的 Agent 资产才可由具备读取权限的本租户成员访问。列表、文本搜索和总数 SHALL 先过滤后分页，组织部门或岗位 MUST NOT 自动扩大范围。

共享回退 SHALL 继续校验实际资产来源的私有/共享归属，不能只凭消费 Agent 的共享属性开放另一 Agent 的私有资产；来源归属缺失 MUST 拒绝读取。

#### Scenario: 同租户读取他人历史
- **WHEN** 普通成员使用同租户另一个人的会话或记忆标识请求内容
- **THEN** 系统拒绝访问，不因该成员有基础读取权限或属于相同部门而放行

#### Scenario: 历史资产不默认公开
- **WHEN** 旧工作空间登记到默认租户后新增一个普通成员
- **THEN** 该成员不能读取初始管理员私有的历史 Agent 资产，只有显式共享且满足权限的内容可见

#### Scenario: 汇总与搜索一致过滤
- **WHEN** 成员查询历史、知识或个人记忆的列表、总数及文本搜索
- **THEN** 结果和总数仅包含其获准范围，搜索不得绕过归属或隐式触发尚未开放的模型调用

#### Scenario: 共享 Agent 引用了私有共享根
- **WHEN** 普通成员从租户共享 Agent 请求的内容实际来自默认 Agent 的私有资产
- **THEN** 系统按实际来源拒绝读取，不因消费 Agent 的共享标识或同租户目录嵌套公开私有内容

### Requirement: 路径解析不回退全局存储

database 模式 SHALL 使用可信租户、Agent 绑定和已登记目录解析业务路径；缺租户、未知 Agent、非法 base 或配置损坏时 SHALL 拒绝。跨租户的规范化目录 MUST 不相等或互相包含，身份数据库和新租户目录不得处于旧租户可读根内；同租户历史父子目录关系可以保留。路径穿越、软链接逃逸和用户提供的任意目录 MUST 不能扩大访问范围。

#### Scenario: 跨租户回退尝试
- **WHEN** 当前租户缺少知识/记忆资产或发生存储解析错误
- **THEN** 系统返回缺失或服务错误，不读取全局默认 Agent、home、其他租户资产或共享凭据

#### Scenario: 新租户目录位于旧租户根内
- **WHEN** 创建或迁移预检发现新租户根或身份数据库会落入另一租户可访问目录
- **THEN** 系统阻止创建或切换，要求配置独立目录，不依赖前端隐藏目录解决冲突

#### Scenario: 合法根下的越界引用
- **WHEN** 内容读取经 base 参数、相对路径或软链接实际指向租户外
- **THEN** 系统在实际读取前拒绝该引用，不能把已登记根当作所有子路径均安全的证明

### Requirement: 首期消费者按明确入口允许或关闭

database 首期 SHALL 只开放已校验的 Web 身份管理、受限审计、安全 Agent 概览、授权历史和知识/个人记忆内容读取、已验收的渠道接入与入站执行、已验收的外部身份绑定维护，以及显式公开白名单。模型/工具执行、文件下载预览上传、SSE/poll/cancel/steer、任意项目、OpenAI API、调度/evolution 和未适配 Desktop 运行入口 SHALL 在服务器端关闭。渠道接入与其入站执行 SHALL 只在其独立 change 的验收（凭据落点、跨租户隔离、入站端到端与启用门槛）通过后开放；启用门槛未满足时 MUST NOT 对外声明该能力可用。启动、构造、重启及间接调用 SHALL 遵守同一关闭规则；未知路由 MUST 默认拒绝，不得按 GET 或菜单隐藏代替授权。

#### Scenario: 直接调用未开放业务接口
- **WHEN** 用户绕过页面调用预览、文件上传、旧流接口或模型执行
- **THEN** 系统返回明确不可用结果，不接受 URL 旧 token，也不因用户是租户管理员而开启未适配能力

#### Scenario: 构造或重启触发后台任务
- **WHEN** database 模式初始化 Bridge、重启通道或触发 scheduler/evolution 的启动入口
- **THEN** 已验收的渠道实例按启用状态启动，未适配消费者不会开始消费，模式切换前的旧线程已随维护重启退出

#### Scenario: 渠道接入在启用门槛未满足时
- **WHEN** 渠道接入能力的前置 change 尚未归档或其启用门槛未满足
- **THEN** 交付表述不声明该能力已可用，且不以页面可达代替隔离验收

#### Scenario: 渠道入站不得回退全局默认
- **WHEN** 经某渠道实例进入的消息在该实例所属租户内无法解析到有效的成员或默认智能体
- **THEN** 系统拒绝该消息并返回固定提示，MUST NOT 回退到全局默认 Agent 或另一租户的资源

#### Scenario: 外部身份绑定维护的边界
- **WHEN** 调用方访问外部身份绑定接口
- **THEN** 仅平台管理员可达平台侧、仅租户管理员可达本租户成员侧、二者都需经路由策略登记；未登记的相邻路由（更长的子路径）MUST 默认拒绝，不得因前缀匹配而放行

#### Scenario: 品牌和原始配置边界
- **WHEN** 客户端读取已发布的最小品牌内容，或尝试原始配置、全局日志、品牌管理写入
- **THEN** 最小公开品牌可读取，其余未适配管理入口拒绝，不将身份库审计误用为品牌文件的跨存储事务保证

### Requirement: 迁移优先登记既有数据

系统 SHALL 提供只读预检、一致备份和受信引导，将既有工作空间明确登记给默认租户及初始管理员，只补必要归属元数据，保持目录、业务 ID 和索引内容。归属或目录有歧义 SHALL 阻止切换，不自动共享、全量复制或忽略异常。迁移重复执行 SHALL 依据版本和唯一约束保持幂等。

#### Scenario: 单实例原地迁移
- **WHEN** 预检无异常且运维完成一致备份和默认租户/管理员指定
- **THEN** 原有 Agent、会话及内容路径保持不变，身份和个人归属明确，旧凭据失效且未适配消费者关闭

#### Scenario: 迁移中断或归属异常
- **WHEN** 迁移遇到未知归属、非法根，或在提交前中断
- **THEN** 系统不启用 database，保留源数据与备份；修复后重试不重复建立租户、成员或归属

### Requirement: 验收后整体启用且不静默降级

系统 SHALL 在双租户与同租户多用户隔离、关闭入口、真实身份审计及恢复演练通过后才启用运行面。高风险消费者只有通过对应的凭据、审批、配额、审计与执行隔离切片验证后才能开放。系统 MUST NOT 提供回退旧身份模式的启动路径；身份库故障时 SHALL 拒绝不安全启动或访问，按相容版本恢复或维护窗口一致快照恢复处理，MUST NOT 使用共享密码或免登录开放数据。

#### Scenario: 只有管理页完成
- **WHEN** 四页功能完成但存在可访问的越租户或未分类业务入口
- **THEN** 运行启用验收失败，不能通过关闭部分菜单宣称多租户隔离已完成

#### Scenario: 新模式发生故障
- **WHEN** 已迁移实例身份库故障
- **THEN** 系统拒绝不安全启动或访问，按相容版本恢复或维护窗口一致快照恢复处理，不自动使用共享密码开放数据

#### Scenario: 后续开放业务消费者
- **WHEN** change 请求开放模型调用、外部凭据动作或任意代码
- **THEN** 必须验证相应配额、凭据、审批或执行隔离切片并补齐消费者授权，不能凭身份管理验收直接放行

### Requirement: 业务存储在租户维度有第二道过滤

会话、消息与记忆索引的写入路径 SHALL 固化为其所属租户，检索路径 SHALL 把该租户维度纳入过滤条件，使租户隔离不再仅依赖「一个 Agent 只属一个租户」的隐式推论。该维度 SHALL 作为纵深防御的第二道门：当 Agent 归属被错误重绑、工作区被跨租户复用或索引被跨租户访问时，检索仍 MUST NOT 返回其他租户的行。

租户维度 SHALL 与既有的所有者维度（逐用户）区分登记，二者语义不重叠：所有者维度标识行的用户归属，租户维度标识行的租户归属，可同时作为过滤条件使用。

既有行在迁移时 SHALL 以其**所有者**对应用户的租户成员关系作为权威归属来源回填；MUST NOT 仅按 Agent 的当前归属回填，因为 Agent 与租户的绑定可被重绑且可能为多对多，按 Agent 回填会产生错误的隔离归属。无法确定归属的旧行 MUST 保持不可跨租户读出，且 MUST NOT 因回填失败丢失或改写原始内容。回滚 SHALL 只需停用第二道过滤，不要求恢复已回填的列值。

#### Scenario: 跨租户读取他人会话行

- **WHEN** 在工作区或索引被跨租户访问的情形下，检索带某租户维度的会话或消息
- **THEN** 结果不包含其他租户的行，且该拒绝由存储层过滤保证，不依赖调用方是否正确校验

#### Scenario: 旧行按所有者回填

- **WHEN** 迁移既有业务库并回填租户维度
- **THEN** 归属按其所有者的租户成员关系确定，与 Agent 当前绑定无关；可确定归属的行被正确回填

#### Scenario: 未启用第二道过滤时的兼容

- **WHEN** 第二道过滤被停用（回滚）
- **THEN** 读写沿用原语义不报错，且不影响既有会话、消息与记忆的可见性

### Requirement: 默认智能体解析校验绑定存在且启用

租户默认智能体的解析 SHALL 校验目标 Agent 的绑定存在且处于启用状态；当配置的默认 Agent 不存在、已解绑或已停用时，系统 SHALL 按确定性顺序在本租户内回退到合法 Agent，MUST NOT 回退到进程全局默认或其他租户的 Agent。回退 SHALL 记录可诊断原因。

#### Scenario: 默认 Agent 指向已解绑对象

- **WHEN** 租户配置的 `default_agent_id` 指向不存在或已解绑的 Agent
- **THEN** 解析在本租户内按确定性顺序回退到合法 Agent，不落到进程全局默认或其他租户的 Agent

#### Scenario: 本租户无任何合法 Agent

- **WHEN** 租户内不存在任何绑定且启用的 Agent
- **THEN** 解析失败并拒绝相关操作，不借用其他租户或平台默认 Agent

#### Scenario: 默认 Agent 被停用

- **WHEN** 租户默认 Agent 被停用后发起需要默认 Agent 的操作
- **THEN** 解析回退到本租户内的合法 Agent，或明确拒绝，均不产生跨租户执行
