## Why

当前 Web 首页的纯黑侧栏、白色顶栏和浅色内容区缺少统一的配色选择，现有深浅切换不能满足用户对背景风格的偏好。根据用户 2026-09-08 的要求，先生成 change，规划可由用户选择并记忆的界面配色，同时给出导航与首页功能改造建议。用户后续提供新的目标截图并明确要求实现，现将对应布局调整纳入本 change。

## What Changes

- 为 Web 控制台提供三套内置配色：**商务青蓝（推荐）**、**深蓝侧栏**、**经典配色**；统一公共框架与对话首页的侧栏、顶栏、主内容背景、卡片、输入框、账号及外观弹层的颜色与交互状态。其他业务页面维持既有深浅适配，本期不承诺全部页面重新配色。
- 将配色方案与明暗模式分开选择：每套配色均支持**浅色、深色、跟随系统**。经典配色保留原有视觉方向，已有用户的有效深浅偏好优先保留。
- 顶部现有主题入口打开轻量外观面板，展示配色缩略预览、名称、选中状态、明暗选项和恢复默认；与账号菜单“界面偏好”复用同一状态及面板，不新增导航页面。
- 选择后立即应用并在当前浏览器保存，支持刷新恢复、多标签同步和本地存储不可用时的本页降级；明确标注“仅在当前浏览器生效”，不宣称账号或跨设备同步。
- 保留品牌 Logo、名称与品牌设置归属；配色调整不改品牌配置、业务数据、页面路由或操作权限。
- 根据用户追加截图实现单顶栏、可折叠侧栏与“新建对话”、资源管理收纳、左对齐欢迎语、位于欢迎语下方的空态输入框、三条任务建议；已有会话继续底部输入，保留全部业务路由及品牌来源。
- 用户已授权 apply，并明确追加上述布局实施；同时补齐复查发现的统一偏好入口、非颜色选中提示及跨身份/租户验收缺口。实现与验收状态见 tasks.md 和 verification.md。

## Capabilities

### New Capabilities

- `workbench-appearance-preferences`：Web 控制台配色预设、明暗模式、统一选择入口、本地偏好恢复与兼容，以及外观覆盖和可访问性验收。

### Modified Capabilities

无。当前 `openspec/specs/` 为空，相关品牌、导航及账号偏好规范仍位于在途 change。本次新增规范，不把在途规范当作已归档基线，也不修改其他 change。

## Impact

- **需求依据**：当前用户请求与首页截图；属于 PRD-02 平台导航 v1.2 的界面偏好增量。仓库配置引用的 `doc/优化规划/PRD/PRD-00-总目录.md` 及 PRD-02 原文当前缺失，依据现有代码与相关 change 设计，原文恢复后复核归属，不声称已逐项核对 PRD。
- **接入范围**：`channel/web/chat.html`、`channel/web/static/js/console.js`，新增独立的 `static/js/appearance.js` 和 `static/css/appearance.css`，后者在既有 `console.css` 后加载；新资源加入 `web_channel.py` 的缓存更新列表。沿用原生 HTML/CSS/JavaScript，不新增运行时依赖、后端接口或数据库字段。
- **数据唯一归属**：当前同源浏览器的 `cow_theme` 负责明暗偏好，拟新增 `cow_web_palette` 负责 Web 配色预设；内存状态是本页投影，CSS 是视觉投影。浏览器内不同登录账号共享设备外观偏好，租户切换不重置；不进入 identity.db、实例 `/config` 或品牌存储。
- **跨 change 协调**：复用 `extend-sidebar-account-actions` 的界面偏好入口及本地偏好约定；外观面板可先由现有顶部主题入口独立提供，不等待改密/租户切换等无关能力。延续 `add-sidebar-account-menu` 的账号显示与交互，仅使颜色适配预设；`add-branding-settings` 继续独占品牌设置。实施与归档时协调重叠条款，使用同一主题状态，禁止双重处理器。
- **兼容边界**：Desktop 已有独立主题目录与 `cow_theme_id`，本次不改桌面主题协议、壁纸、安装图标或 Channel；不提供任意颜色输入、上传背景图、自定义 CSS、租户强制主题或跨设备偏好服务。
- **启用门槛**：此能力仅改变本地视觉，无新增 feature flag；验收现有 database/legacy/免登录模式下适用入口与存储降级，不以账号其他能力完成作为发布门槛。无模型执行、凭据或实例写入，不新增审计、审批与配额消费者；现有认证及企业运行门禁维持原职责。
