# 设计：手册重建为截图与步骤

## 决策

### D1：形态取「截图 + 编号步骤」，不取视频

使用者的诉求是「照着能做完一件事」。视频能表达动态过程，但必须先有视频；截图 + 步骤可以立即交付，且与界面同源、可被结构校验（D6 断言图片存在）。

代价是截图会随界面改版过期——一个步骤可能因为按钮改名而失真。缓解办法是把「会过期的部分」限制在截图本身：正文的操作要点写界面上稳定的名称（页面名、控件名），不写像素坐标与位置描述（「右上角第三个图标」这类说法改版即失效）。

### D2：主题收敛为 5 个，且只收成员能做的主

服务对象是**租户成员**（本次取 `RC001`，仅有 `member` 角色）。因此：

- 保留：发起对话、多智能体协同对话、设置本人知识库、创建与配置本人智能体、接入消息渠道——这五项在 `member` 角色下可见可做。
- 剔除：成员与组织、角色权限、租户与审计、模型服务（租户级配置）等管理侧主题。这些页面对 `member` 不可见，写进手册会让成员照做时撞到「无权访问」。
- 剔除：命令速查、故障排查、深入阅读等参考类主题。它们是查阅型内容，不是操作流程；命令清单仍在站点其它页面维护，手册不再复制。

### D3：分组由三组收敛为两组

原分组「工作台 / 管理控制台 / 个人与参考」是按**界面区域**分的。收敛到 5 个成员操作后，界面区域不再构成有意义的区分（五项都在成员可见范围内，其中消息渠道页面实际挂在 `/admin` 外壳下但内容是本人的渠道）。

改按**使用者的心智**分组：

- 「对话与协作」：发起对话、多智能体协同对话——都在对话界面内完成。
- 「我的资源」：知识库、智能体、消息渠道——都是「属于我、我来维护」的资源。

### D4：步骤的数据形状

```php
[
    'id' => 'chat', 'part' => 'conversation', 'icon' => 'chat',
    'steps' => [
        ['id' => 'compose', 'shot' => 'img/manual/chat-1-compose.png'],
        ['id' => 'agent',   'shot' => 'img/manual/chat-2-agent.png'],
    ],
    'docs' => [], 'links' => [],
]
```

- `steps[].id` 是稳定键，锚点为 `#manual-<主题>-<步骤>`。
- `steps[].shot` 是相对 `assets/` 的路径，经 `asset()` 输出。它**不写网址**，因此仍满足「正文不出现网址」。
- 步骤文案在 `lang/*.php` 的 `manual.topics.<主题>.steps.<步骤>.{title,body}`：`title` 是这一步要达成的目标（名词短语），`body` 是操作要点。刻意不叫 `steps`/`fields`——那是上一版已被证明「改版即过期」的细粒度字段口径。

### D5：截图取真实界面，不修图不改数据

截图在真实运行的控制台上按真实操作路径捕获，用成员 `RC001` 登录。为了截图有意义而**真实创建**了最小演示数据（知识库分类 `Policies` 与一篇文档），未创建多余智能体与渠道——那两者会出现在每次对话的智能体挑选器与渠道列表里，属于使用者日常可见的残留。

登录步骤的截图以 JPEG 存储：该页有整幅渐变背景，同尺寸下 PNG 为 1.6 MB、JPEG 为 229 KB，视觉差异可忽略。

### D6：校验新增「截图存在性」断言

`tools/check-manual.php` 此前只比对结构键与文案，从不检查引用的资源是否真实存在。截图是本版手册的承重内容，缺图会直接呈现为破图。因此新增断言：每个步骤声明的 `shot` 在 `assets/` 下存在，缺失则以非零状态退出并指出主题与步骤。

同时保留并调整为：主题/步骤的双语键对齐、每个步骤有目标与操作要点、引用的文档 slug 经 `doc_exists()` 过滤、引用的站内页面 id 在 `manual_page_links` 中登记。

### D7：删除录屏脚本

`manual-video-scripts.md` 的键是 `主题.视频`，与视频清单绑定。手册不再有视频条目后，这份文件既是孤儿又会让校验失败。其中来自上一版手册的界面操作事实已经改写进新的编号步骤，历史内容保留在提交 `cbdb9884`。

## 未决

- 截图会随界面改版过期。当前没有自动发现「截图与界面不一致」的手段（只有「图片存在」）。可行方向是录制端到端用例时顺带产出截图，但那是另一个 change。
- 英文站点复用同一批中文界面截图。英文界面截图需要以英文语言环境重跑一遍捕获，本次未做。
