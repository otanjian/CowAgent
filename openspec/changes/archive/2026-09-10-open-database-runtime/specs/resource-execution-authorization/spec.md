## MODIFIED Requirements

### Requirement: 现有调用点接入与运行开放分别验收

本能力 SHALL 将授权接入现有技能装配、工具实际分发、Agent 委派、模型请求以及已开放的 Web/通道/调度等运行路径，以真实身份库和受控本地工具/模型替身验证实际分发结果，不能仅验证独立判断函数或界面。目录/配置/运行状态分别报告。对已由 `database-runtime-consumers` 与 `external-identity-binding` 验收开放的消费者，系统 SHALL 允许合法授权请求真实执行，并在缺权、撤权或 IM 未绑定时拒绝；尚未适配的客户端（例如 Desktop 企业登录）SHALL 维持正式关闭边界。组件集成证据不得描述为未开放客户端已可用。

#### Scenario: 合法与非法资源到达实际分发组件
- **WHEN** 集成测试用真实身份上下文通过现有装配和分发代码发起受控工具或模型调用
- **THEN** 合法资源命中预期替身，未授权或撤权资源在分发前拒绝；记录组件证据

#### Scenario: 守卫接入完成但Web仍关闭
- **WHEN** 角色配置及实际组件授权验收通过，且运行开放已由本 change 验收，但调用者缺少 `chat.use`/目标 `agent.use`，或 Desktop 等未适配客户端仍关闭
- **THEN** 缺权 Web 请求返回 403 类拒绝；未适配客户端保持关闭说明；获权 Web/已适配通道按开放边界执行，发布说明不把未适配客户端写成可用
