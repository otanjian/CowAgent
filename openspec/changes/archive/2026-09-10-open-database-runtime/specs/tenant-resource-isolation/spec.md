## MODIFIED Requirements

### Requirement: 首期消费者按明确入口允许或关闭

database 模式下，模型/工具执行、文件下载预览上传、SSE/poll/cancel/steer、任意项目、OpenAI API、外部通道、调度/evolution 与 Desktop 运行入口 SHALL 在相应切片验收前于服务器端关闭；对应切片验收通过后 SHALL 按身份、资源授权、执行隔离、凭据、审批与配额开放。启动、构造、重启及间接调用 SHALL 遵守同一规则；未知路由 MUST 默认拒绝，不得按 GET 或菜单隐藏代替授权。纯 LLM 对话与只读目录不视为上述高风险执行。

#### Scenario: 直接调用未开放业务接口
- **WHEN** 用户绕过页面调用未验收的预览、文件上传、旧流接口或模型/代码执行
- **THEN** 系统返回明确不可用结果，不接受 URL 旧 token，也不因用户是租户管理员而开启未验收能力

#### Scenario: 构造或重启触发后台任务
- **WHEN** database 模式初始化 Bridge、重启通道或触发 scheduler/evolution 的启动入口，而对应切片未验收
- **THEN** 未验收消费者不会开始消费；已验收消费者按授权与隔离启动，模式切换前的旧线程已随维护重启退出

#### Scenario: 品牌和原始配置边界
- **WHEN** 客户端读取已发布的最小品牌内容，或尝试原始配置、全局日志、品牌管理写入
- **THEN** 最小公开品牌可读取，其余未适配管理入口拒绝，不将身份库审计误用为品牌文件的跨存储事务保证

### Requirement: 验收后整体启用且不静默降级

系统 SHALL 在双租户与同租户多用户隔离、关闭入口、真实身份审计及恢复演练通过后才启用 database 运行面。启用通过维护窗口重启完成，不需要另设第二租户特权开关。已有迁移标识或新模式数据时 MUST 阻止直接启动 legacy 读取数据；高风险消费者只有通过对应的凭据（08S）、审批（09G）、配额（10B）、审计（10A）与执行隔离切片验证后才能开放。

#### Scenario: 只有管理页完成
- **WHEN** 四页功能完成但存在可访问的越租户或未分类业务入口
- **THEN** database 运行启用验收失败，不能通过关闭部分菜单宣称多租户隔离已完成

#### Scenario: 新模式发生故障
- **WHEN** 已迁移实例身份库故障或配置试图回到 legacy
- **THEN** 系统拒绝不安全启动或访问，按相容版本恢复或维护窗口一致快照恢复处理，不自动使用共享密码开放数据

#### Scenario: 后续开放业务消费者
- **WHEN** change 请求开放模型调用、外部凭据动作或任意代码
- **THEN** 必须验证相应 10B、08S、09G 或执行隔离切片并补齐消费者授权，不能凭身份管理验收直接放行；本 change 已把这些切片纳入交付并逐一切片验收
