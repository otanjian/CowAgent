## MODIFIED Requirements

### Requirement: 首期消费者按明确入口允许或关闭

database 首期 SHALL 只开放已校验的 Web 身份管理、受限审计、安全 Agent 概览、授权历史和知识/个人记忆内容读取、已验收的渠道接入与入站执行、已验收的外部身份绑定维护，以及显式公开白名单。模型/工具执行、文件下载预览上传、SSE/poll/cancel/steer、任意项目、OpenAI API、调度/evolution 和未适配 Desktop 运行入口 SHALL 在服务器端关闭。渠道接入与其入站执行 SHALL 只在其独立 change 的验收（凭据落点、跨租户隔离、入站端到端与启用门槛）通过后开放；启用门槛未满足时 MUST NOT 对外声明该能力可用。启动、构造、重启及间接调用 SHALL 遵守同一关闭规则；未知路由 MUST 默认拒绝，不得按 GET 或菜单隐藏代替授权。

#### Scenario: 直接调用未开放业务接口
- **WHEN** 用户绕过页面调用预览、文件上传、旧流接口或模型执行
- **THEN** 系统返回明确不可用结果，不接受 URL 旧 token，也不因用户是租户管理员而开启未适配能力

#### Scenario: 构造或重启触发后台任务
- **WHEN** database 模式初始化 Bridge、重启通道或触发 scheduler/evolution 的启动入口
- **THEN** 已验收的渠道实例按启用状态启动，未适配消费者不会开始消费，模式切换前的旧线程已随维护重启退出

#### Scenario: 渠道接入在启用门槛未满足时
- **WHEN** 渠道接入能力的前置 change 尚未归档或其启用门槛未满足
- **THEN** 交付表述不声明该能力已可用，且不以页面可达代替隔离验收

#### Scenario: 渠道入站不得回退全局默认
- **WHEN** 经某渠道实例进入的消息在该实例所属租户内无法解析到有效的成员或默认智能体
- **THEN** 系统拒绝该消息并返回固定提示，MUST NOT 回退到全局默认 Agent 或另一租户的资源

#### Scenario: 外部身份绑定维护的边界
- **WHEN** 调用方访问外部身份绑定接口
- **THEN** 仅平台管理员可达平台侧、仅租户管理员可达本租户成员侧、二者都需经路由策略登记；未登记的相邻路由（更长的子路径）MUST 默认拒绝，不得因前缀匹配而放行

#### Scenario: 品牌和原始配置边界
- **WHEN** 客户端读取已发布的最小品牌内容，或尝试原始配置、全局日志、品牌管理写入
- **THEN** 最小公开品牌可读取，其余未适配管理入口拒绝，不将身份库审计误用为品牌文件的跨存储事务保证
