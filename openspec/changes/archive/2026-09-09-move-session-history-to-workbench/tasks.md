## 实施与交互验证记录

以下记录属于原导航迁移阶段；第 6～7 节的独立实施与验证记录见文末。原阶段的 API 不变结论仅适用于导航迁移，本轮为列表 API 增加兼容旧调用的可选标题查询。

- **OpenSpec 严格校验**：`openspec validate move-session-history-to-workbench` 通过（"Change is valid"），spec 每项 requirement 均含 SHALL/MUST 与 WHEN/THEN 场景。
- **浏览器已验证（真实数据，当前 legacy 模式、单默认空间、已配置 Web 登录）**：
  - 工作台菜单顺序：对话 → 历史会话 → 智能体 → 待办 → 定时 → 场景应用；`history` 位于「对话」之后。
  - 点击「历史会话」进入独立主内容页，激活菜单，面包屑「工作台 / 历史会话」，标题「历史会话」。
  - 会话列表加载并分组（今天/更早），点击条目切到「对话」且恢复对应 sessionId。
  - 置顶/取消置顶：条目移入「置顶」组并回到原组，按钮标题随态翻转；当前标记 active 正确。
  - 重命名：行内输入框出现，Enter 提交并持久化（已还原原标题），Escape/空值回退。
  - 删除：确认弹窗（"删除会话 / 确认删除该会话？所有消息将被清除。"）出现并取消正常关闭。
  - 「新对话」按钮：多智能体模式展开 `new-chat-menu`（RongAI/erpnext），选择后新建 session 并进入「对话」+ 欢迎屏。
  - 刷新按钮（图标）触发列表重载，无错误/空态误报。
  - 移动端宽度（390×844）：`.history-head/.history-status/.session-list` 均应用 `16px` 内边距（修复了原先 `.session-list` 移动内边距被基础规则覆盖的级联问题）；暗色主题下标题/说明/按钮配色正确。
  - 长标题：`.session-title` `text-overflow:ellipsis` + `white-space:nowrap`，无横向溢出。
- **条件依赖、未在本环境复现（故 4.2/4.3/4.4 未勾选）**：
  - 项目分组（多工作空间）、项目折叠/拖动排序、项目重命名/删除。
  - 超过两页的分页与首屏不足一屏、分页失败重试。
  - 真实移动端触摸、多智能体团队对话、键盘焦点遍历。
  - database IAM 身份模式（当前为 legacy 模式，未启用）——按 4.4 明确记为未验证，不纳入身份域验收。
