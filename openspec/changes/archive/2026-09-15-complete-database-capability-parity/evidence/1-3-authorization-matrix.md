# 1.3 访问矩阵（本人 / 同租户他人 / 租户管理员 / 平台管理员 / 跨租户 / 失效成员 / 无租户）

- 记录日期：2026-09-15
- 用途：把「私有内容」「公共管理」「治理元数据」三类目标按身份角色逐格定死，作为
  3.x/5.x/6.x/7.x 各切片的判定基线，也作为 11.x 联合验收的对照表。
- 判定来源（唯一实现，不自建第二套）：`agent/tools/scheduler/authorization.py`
  （任务与调度动作）、`common/safe_fs.py` + `agent/memory/personal.py`（个人记忆归属）、
  `auth/capability_matrix.py`（切片策略与动作类别）、`auth/http_policy.py` +
  `auth/runtime.py`（会话、租户、Membership、平台身份的解析顺序）。

## 1. 判定顺序（与设计 D1 一致）

1. 有效会话（无会话 → 401）；
2. 有效租户与 Membership（租户内业务要求已选租户；缺选择 → 400，非成员/未知租户 → 403/404）；
3. 实际资源归属（owner / 私有 Agent / 本人项目根 / 本人记忆域）；
4. 允许动作（read / config / execute 三类，见 `auth/capability_matrix.py`）；
5. 运行条件（配额、部署开关、实例连接状态、执行隔离、适用审批）。

个人身份域（账号设置）与平台接口不要求租户选择；租户内个人业务（个人记忆、个人渠道、
本人任务）仍要求有效租户，不因 URL 含 `personal` 而豁免。

## 2. 私有内容（本人任务/本人记忆/本人项目/私有 Agent 资源）

| 角色 | 读取 | 配置（改/删/启停） | 执行（run） | 依据 |
| --- | --- | --- | --- | --- |
| 本人 | 允许 | 允许（含已撤 `agent.use`，避免任务被搁死） | 允许（隔离停用任务除外 → `quarantined`） | `TaskAccessService.decide`：`scope == personal` → `is_owner` 即 view/manage；run 额外查隔离 |
| 同租户他人 | 拒绝（不读正文、不返回条目） | 拒绝 | 拒绝 | 同上，`NOT_OWNER` |
| 租户管理员（非 owner） | 拒绝 | 拒绝 | 拒绝 | 私有对象的非 owner 判断位于公共权限之前；管理员只在 `public` scope 分支被放行 |
| 平台管理员（非 owner、无租户） | 拒绝（治理元数据除外，见第 4 节） | 拒绝 | 拒绝 | `decide` 首查 `actor.is_member`；平台身份不伪造 Membership |
| 跨租户成员 | 拒绝（不泄露存在性） | 拒绝 | 拒绝 | `list_agent_ids`/`store` 只解析当前租户的 Agent；跨租户 Agent 解析为不可用 |
| 失效/被撤权成员 | 本人任务仍可 view/manage/delete（`agent.use` 已撤不搁死），run 拒绝；他人私有内容一律拒绝 | 同左 | 拒绝 | `decide` + `_can_use_agent`（run 需要 `agent.use`） |
| 无租户账号 | 拒绝（租户内业务要求有效租户） | 拒绝 | 拒绝 | `actor.is_member` 为假；`/auth/me`、账号设置、退出仍可用 |

## 3. 公共管理（Agent 自有任务、租户共享渠道实例、公共知识/技能）

| 角色 | 读取 | 配置 | 执行 | 依据 |
| --- | --- | --- | --- | --- |
| 租户管理员 | 允许 | 允许 | 允许（隔离停用 → `quarantined`） | `decide` 的 `public` 分支：`actor.is_admin` |
| 本人（非管理员，同租户） | 允许 | 拒绝（`not_owner`） | 拒绝（除非另有 `agent.use` 与资源授权） | 同上；公共读取是成员可见的，公共维护不是 |
| 同租户他人 | 允许（只读） | 拒绝 | 拒绝 | 同上 |
| 平台管理员 | 只有治理元数据，可管理平台级对象；不等同租户管理员 | 见第 4 节 | 拒绝租户内个人执行 | 平台身份不自动获得租户 `agent.use`，也不进租户业务域 |
| 跨租户 | 拒绝 | 拒绝 | 拒绝 | 租户解析前置 |

## 4. 治理元数据（归属、数量、配额用量、治理状态）

| 角色 | 可见内容 | 明确不可见 |
| --- | --- | --- |
| 平台管理员 | 归属（owner/tenant/scope）、任务数量与配额用量、隔离/停用状态 | 任务标题与提示词、任务 action 正文、记忆正文、目录内容、消息、任何密钥 |
| 租户管理员 | 本租户公共对象的归属与用量，成员的私有对象**不计入**其可见范围 | 成员私有任务标题/正文/接收目标 |
| 本人 | 自己全部的元数据 | 他人任何内容 |

审计只记录动作、对象标识、结果与拒绝码，不记录任务正文或凭据原文
（`TaskAccessService._audit`、`IdentityService.record_business_audit` 的脱敏约定）。

## 5. 与 3.1 条款的对应

| 产品规划 3.1 条款 | 本矩阵落点 |
| --- | --- |
| 3.1.2 规则 1/3/8（三级架构、个人入口按 owner、页面与对象动作分开） | 第 2 节列；`capabilities()` 由同一 `decide()` 派生，页面不自行判定 |

| 3.1.3 租户管理员 2.3 / 成员 3.3（机器人接入不是成员身份证明） | 扫码结果只证明接入控制权；私有私聊路由另需本人身份挑战 |
