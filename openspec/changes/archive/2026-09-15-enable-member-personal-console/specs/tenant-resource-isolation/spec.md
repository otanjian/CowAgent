## MODIFIED Requirements

### Requirement: 个人与共享资源有明确边界

系统 SHALL 在租户和 Agent 校验之后继续检查实际资源所有者与当前动作授权。本人会话、执行记录、个人记忆与私有 Agent 资产 SHALL 仅由对应 owner 访问；tenant_admin 与平台管理员的业务读取资格 MUST NOT 绕过该边界，其治理投影不包含成员私有正文。历史 Agent 资产 SHALL 默认归初始管理员私有，只有明确登记共享的 Agent 资产才可由具备读取权限的本租户成员访问。列表、文本搜索和总数 SHALL 先过滤后分页，组织部门或岗位 MUST NOT 自动扩大范围。

共享回退 SHALL 继续校验实际资产来源的私有/共享归属，不能只凭消费 Agent 的共享属性开放另一 Agent 的私有资产；来源归属缺失 MUST 拒绝读取。

归属校验 SHALL 同样覆盖**文件服务数据面**，与列表、文本搜索和记忆读取使用同一规则：以绝对路径、相对路径（含租户共享根之下的目录嵌套）或服务端签发 URL 请求文件时，系统 SHALL 解析该被寻址资源**所属 Agent** 并校验其私有/共享归属（仅属主本人放行；管理员资格不形成私有读取旁路），MUST NOT 仅凭调用者对租户的成员资格、或仅凭「路径位于调用者租户共享根内」放行同租户其他成员的私有 Agent 资产；目录列举与搜索 SHALL 同样过滤。请求自报的 Agent 标识 MUST NOT 作为授权来源。归属 MUST 取最具体的命中根；归属无法唯一确定时 MUST 失败关闭并按不可见拒绝。

#### Scenario: 同租户读取他人历史
- **WHEN** 普通成员使用同租户另一个人的会话或记忆标识请求内容
- **THEN** 系统拒绝访问，不因该成员有基础读取权限或属于相同部门而放行

#### Scenario: 历史资产不默认公开
- **WHEN** 旧工作空间登记到默认租户后新增一个普通成员
- **THEN** 该成员不能读取初始管理员私有的历史 Agent 资产，只有显式共享且满足权限的内容可见

#### Scenario: 汇总与搜索一致过滤
- **WHEN** 成员查询历史、知识或个人记忆的列表、总数及文本搜索
- **THEN** 结果和总数仅包含其获准范围，搜索不得绕过归属或隐式触发尚未开放的模型调用

#### Scenario: 共享 Agent 引用了私有共享根
- **WHEN** 普通成员从租户共享 Agent 请求的内容实际来自默认 Agent 的私有资产
- **THEN** 系统按实际来源拒绝读取，不因消费 Agent 的共享标识或同租户目录嵌套公开私有内容

#### Scenario: 管理员经共享根访问成员私有文件

- **WHEN** 非 owner 管理员经共享根、平台父目录或另一共享 Agent 定位到成员私有资产
- **THEN** 按实际资产 owner 拒绝读取，不因管理资格、目录包含关系或客户端 agent 参数放行

#### Scenario: 同租户成员以绝对路径读取他人私有 Agent 文件

- **WHEN** 普通成员（非该 Agent 属主）以绝对路径请求同租户内他人私有 Agent workspace 中的文件，无论请求声明的 Agent 参数是否为共享 Agent
- **THEN** 系统按不可见拒绝（403 或 404），不返回文件内容或路径存在性

#### Scenario: 目录嵌套不公开私有 Agent 内容

- **WHEN** 普通成员（非该 Agent 属主）以相对路径请求、或列举一个位于本租户共享根之下的他人私有 Agent workspace
- **THEN** 系统拒绝读取并在列举中省略该 Agent，不因「嵌套在共享根内」公开其内容或路径存在性

#### Scenario: 私有 Agent 仅属主可读正文

- **WHEN** 私有 Agent 的属主本人，或同租户的 `tenant_admin`，以绝对路径请求该私有 Agent workspace 中的文件
- **THEN** 属主本人返回内容、归属校验不阻止合法读取；`tenant_admin` 不因管理资格取得正文，仅经治理接口获得归属与用量元数据

#### Scenario: 归属无法唯一确定时失败关闭

- **WHEN** 被请求路径同时落在同租户两个不同 Agent 的 workspace 之下，或无法解析出唯一归属
- **THEN** 系统按不可见拒绝，不任选其一的 Agent 归属放行

### Requirement: 首期消费者按明确入口允许或关闭

database 模式 SHALL 仅开放已校验的身份管理、受限审计、安全 Agent 概览、获准历史和知识/个人记忆，以及分别验收的个人控制台维护、渠道配置、外部身份绑定和业务运行消费者。个人配置、目录读取与实际执行 SHALL 分别验收；模型/工具执行、文件服务、调度、SSE/poll/cancel/steer、项目、OpenAI API 和 Desktop 等入口只在各自真实切片通过后开放，未适配部分 SHALL 在服务器端关闭。

个人渠道接入与入站执行 SHALL 在凭据落点、身份验证、同租户跨用户与跨租户隔离、配额、审计及运行依赖通过后开放；个人记忆与私有工作区写入 SHALL 具备真实 owner 和路径隔离证据。启动、构造、重启及间接调用 SHALL 遵守相同条件；未知路由默认拒绝，不以 GET、菜单隐藏、接口占位或任务勾选代替授权和验收。

#### Scenario: 直接调用未开放业务接口
- **WHEN** 用户绕过页面调用尚未验收开放的预览、文件上传、旧流接口或模型执行
- **THEN** 系统返回明确不可用结果，不接受 URL 旧 token，也不因用户是租户管理员而开启未适配能力

#### Scenario: 构造或重启触发后台任务
- **WHEN** database 模式初始化 Bridge、重启通道或触发 scheduler/evolution 的启动入口
- **THEN** 已验收的渠道实例按启用状态启动，未适配消费者不会开始消费，模式切换前的旧线程已随维护重启退出

#### Scenario: 渠道接入在启用门槛未满足时
- **WHEN** 渠道接入能力所需的实际依赖切片或启用门槛未满足
- **THEN** 交付表述不声明该能力已可用，且不以页面可达代替隔离验收

#### Scenario: 渠道入站不得回退全局默认
- **WHEN** 经某渠道实例进入的消息在该实例所属租户内无法解析到有效的成员或默认智能体
- **THEN** 系统拒绝该消息并返回固定提示，MUST NOT 回退到全局默认 Agent 或另一租户的资源

#### Scenario: 外部身份绑定维护的边界
- **WHEN** 调用方访问外部身份绑定接口
- **THEN** 平台管理侧仅平台管理员可达，租户成员管理侧仅租户管理员可达，本人自助侧只接受已验证当前成员及受验证流程；三者均需逐方法登记路由策略，未登记的相邻路由 MUST 默认拒绝，不得因前缀匹配或自助资格取得管理权限

#### Scenario: 品牌和原始配置边界
- **WHEN** 客户端读取已发布的最小品牌内容，或尝试原始配置、全局日志、品牌管理写入
- **THEN** 最小公开品牌可读取，其余未适配管理入口拒绝，不将身份库审计误用为品牌文件的跨存储事务保证
