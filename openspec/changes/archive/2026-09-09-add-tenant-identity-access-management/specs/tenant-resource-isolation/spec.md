## Purpose

规定最小身份管理版本的租户资源隔离、个人数据归属和迁移契约，在复用现有 Agent 存储的同时阻止跨租户路径及默认回退，并明确首期未适配运行消费者的关闭边界，避免以管理页面完成代替业务隔离验收。

## ADDED Requirements

### Requirement: Agent 租户绑定与现有标识保持稳定

系统 SHALL 保持 Agent ID 全局唯一并为每个可访问 Agent 建立唯一租户绑定；读取 Agent 或业务存储前 SHALL 校验该绑定。租户列表和默认 Agent 选择 SHALL 只在当前租户内进行，无 Agent 时返回空列表。既有业务 session/run ID 和每 Agent 存储 SHALL 保持兼容，未绑定或绑定读取失败时 MUST 拒绝访问而不是使用全局默认 Agent。

#### Scenario: 读取本租户安全概览
- **WHEN** 有权成员请求本租户的 Agent 列表
- **THEN** 仅返回已绑定且获准查看的 Agent 名称等安全字段，不返回 workspace、模型凭据或其他租户记录

#### Scenario: 相同会话标识属于不同 Agent
- **WHEN** 两租户的不同全局 Agent 使用相同业务 session 字符串
- **THEN** 请求仅能访问所选租户合法 Agent 下的记录，不能靠 session 字符串控制另一租户资源

#### Scenario: 缺失或损坏绑定
- **WHEN** 新租户没有 Agent，或绑定/配置读取失败
- **THEN** 无 Agent 时返回空列表，读取失败时拒绝操作，均不选取其他租户或平台默认 Agent

### Requirement: 个人与共享资源有明确边界

系统 SHALL 在租户和 Agent 校验之后继续检查个人资源所有者与功能权限。普通成员只能读取本人会话、执行记录和个人记忆；tenant_admin 可按管理权限读取本租户资源。历史 Agent 资产 SHALL 默认归初始管理员私有，只有明确登记共享的 Agent 资产才可由具备读取权限的本租户成员访问。列表、文本搜索和总数 SHALL 先过滤后分页，组织部门或岗位 MUST NOT 自动扩大范围。

共享回退 SHALL 继续校验实际资产来源的私有/共享归属，不能只凭消费 Agent 的共享属性开放另一 Agent 的私有资产；来源归属缺失 MUST 拒绝读取。

#### Scenario: 同租户读取他人历史
- **WHEN** 普通成员使用同租户另一个人的会话或记忆标识请求内容
- **THEN** 系统拒绝访问，不因该成员有基础读取权限或属于相同部门而放行

#### Scenario: 历史资产不默认公开
- **WHEN** 旧工作空间登记到默认租户后新增一个普通成员
- **THEN** 该成员不能读取初始管理员私有的历史 Agent 资产，只有显式共享且满足权限的内容可见

#### Scenario: 汇总与搜索一致过滤
- **WHEN** 成员查询历史、知识或个人记忆的列表、总数及文本搜索
- **THEN** 结果和总数仅包含其获准范围，搜索不得绕过归属或隐式触发尚未开放的模型调用

#### Scenario: 共享 Agent 引用了私有共享根
- **WHEN** 普通成员从租户共享 Agent 请求的内容实际来自默认 Agent 的私有资产
- **THEN** 系统按实际来源拒绝读取，不因消费 Agent 的共享标识或同租户目录嵌套公开私有内容

### Requirement: 路径解析不回退全局存储

database 模式 SHALL 使用可信租户、Agent 绑定和已登记目录解析业务路径；缺租户、未知 Agent、非法 base 或配置损坏时 SHALL 拒绝。跨租户的规范化目录 MUST 不相等或互相包含，身份数据库和新租户目录不得处于旧租户可读根内；同租户历史父子目录关系可以保留。路径穿越、软链接逃逸和用户提供的任意目录 MUST 不能扩大访问范围。

#### Scenario: 跨租户回退尝试
- **WHEN** 当前租户缺少知识/记忆资产或发生存储解析错误
- **THEN** 系统返回缺失或服务错误，不读取全局默认 Agent、home、其他租户资产或共享凭据

#### Scenario: 新租户目录位于旧租户根内
- **WHEN** 创建或迁移预检发现新租户根或身份数据库会落入另一租户可访问目录
- **THEN** 系统阻止创建或切换，要求配置独立目录，不依赖前端隐藏目录解决冲突

#### Scenario: 合法根下的越界引用
- **WHEN** 内容读取经 base 参数、相对路径或软链接实际指向租户外
- **THEN** 系统在实际读取前拒绝该引用，不能把已登记根当作所有子路径均安全的证明

### Requirement: 首期消费者按明确入口允许或关闭

database 首期 SHALL 只开放已校验的 Web 身份管理、受限审计、安全 Agent 概览、授权历史和知识/个人记忆内容读取，以及显式公开白名单。模型/工具执行、文件下载预览上传、SSE/poll/cancel/steer、任意项目、OpenAI API、外部通道、调度/evolution 和未适配 Desktop 运行入口 SHALL 在服务器端关闭。启动、构造、重启及间接调用 SHALL 遵守同一关闭规则；未知路由 MUST 默认拒绝，不得按 GET 或菜单隐藏代替授权。

#### Scenario: 直接调用未开放业务接口
- **WHEN** 用户绕过页面调用预览、文件上传、旧流接口或模型执行
- **THEN** 系统返回明确不可用结果，不接受 URL 旧 token，也不因用户是租户管理员而开启未适配能力

#### Scenario: 构造或重启触发后台任务
- **WHEN** database 模式初始化 Bridge、重启通道或触发 scheduler/evolution 的启动入口
- **THEN** 未适配消费者不会开始消费，模式切换前的旧线程已随维护重启退出

#### Scenario: 品牌和原始配置边界
- **WHEN** 客户端读取已发布的最小品牌内容，或尝试原始配置、全局日志、品牌管理写入
- **THEN** 最小公开品牌可读取，其余未适配管理入口拒绝，不将身份库审计误用为品牌文件的跨存储事务保证

### Requirement: 迁移优先登记既有数据

系统 SHALL 提供只读预检、一致备份和受信引导，将既有工作空间明确登记给默认租户及初始管理员，只补必要归属元数据，保持目录、业务 ID 和索引内容。归属或目录有歧义 SHALL 阻止切换，不自动共享、全量复制或忽略异常。迁移重复执行 SHALL 依据版本和唯一约束保持幂等。

#### Scenario: 单实例原地迁移
- **WHEN** 预检无异常且运维完成一致备份和默认租户/管理员指定
- **THEN** 原有 Agent、会话及内容路径保持不变，身份和个人归属明确，旧凭据失效且未适配消费者关闭

#### Scenario: 迁移中断或归属异常
- **WHEN** 迁移遇到未知归属、非法根，或在提交前中断
- **THEN** 系统不启用 database，保留源数据与备份；修复后重试不重复建立租户、成员或归属

### Requirement: 验收后整体启用且不静默降级

系统 SHALL 在双租户与同租户多用户隔离、关闭入口、真实身份审计及恢复演练通过后才启用 database。启用通过维护窗口重启完成，不需要另设第二租户特权开关。已有迁移标识或新模式数据时 MUST 阻止直接启动 legacy 读取数据；后续消费者只有通过适用的凭据、审批、配额和执行隔离切片验证才能开放。

#### Scenario: 只有管理页完成
- **WHEN** 四页功能完成但存在可访问的越租户或未分类业务入口
- **THEN** database 启用验收失败，不能通过关闭部分菜单宣称多租户隔离已完成

#### Scenario: 新模式发生故障
- **WHEN** 已迁移实例身份库故障或配置试图回到 legacy
- **THEN** 系统拒绝不安全启动或访问，按相容版本恢复或维护窗口一致快照恢复处理，不自动使用共享密码开放数据

#### Scenario: 后续开放业务消费者
- **WHEN** 后续 change 请求开放模型调用、外部凭据动作或任意代码
- **THEN** 必须验证相应 10B、08S、09G 或执行隔离切片并补齐消费者授权，不能凭本次身份管理验收直接放行
