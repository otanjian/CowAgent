## MODIFIED Requirements

### Requirement: 个人与共享资源有明确边界

系统 SHALL 在租户和 Agent 校验之后继续检查个人资源所有者与功能权限。普通成员只能读取本人会话、执行记录和个人记忆；tenant_admin 可按管理权限读取本租户资源。历史 Agent 资产 SHALL 默认归初始管理员私有，只有明确登记共享的 Agent 资产才可由具备读取权限的本租户成员访问。列表、文本搜索和总数 SHALL 先过滤后分页，组织部门或岗位 MUST NOT 自动扩大范围。

共享回退 SHALL 继续校验实际资产来源的私有/共享归属，不能只凭消费 Agent 的共享属性开放另一 Agent 的私有资产；来源归属缺失 MUST 拒绝读取。

归属校验 SHALL 同样覆盖**文件服务数据面**，与列表、文本搜索和记忆读取使用同一规则：以绝对路径、相对路径（含租户共享根之下的目录嵌套）或服务端签发 URL 请求文件时，系统 SHALL 解析该被寻址资源**所属 Agent** 并校验其私有/共享归属，MUST NOT 仅凭调用者对租户的成员资格、或仅凭「路径位于调用者租户共享根内」放行同租户其他成员的私有 Agent 资产；目录列举与搜索 SHALL 同样过滤。请求自报的 Agent 标识 MUST NOT 作为授权来源。归属 MUST 取最具体的命中根；归属无法唯一确定时 MUST 失败关闭并按不可见拒绝。

#### Scenario: 同租户读取他人历史

- **WHEN** 普通成员使用同租户另一个人的会话或记忆标识请求内容
- **THEN** 系统拒绝访问，不因该成员有基础读取权限或属于相同部门而放行

#### Scenario: 历史资产不默认公开

- **WHEN** 旧工作空间登记到默认租户后新增一个普通成员
- **THEN** 该成员不能读取初始管理员私有的历史 Agent 资产，只有显式共享且满足权限的内容可见

#### Scenario: 汇总与搜索一致过滤

- **WHEN** 成员查询历史、知识或个人记忆的列表、总数及文本搜索
- **THEN** 结果和总数仅包含其获准范围，搜索不得绕过归属或隐式触发尚未开放的模型调用

#### Scenario: 共享 Agent 引用了私有共享根

- **WHEN** 普通成员从租户共享 Agent 请求的内容实际来自默认 Agent 的私有资产
- **THEN** 系统按实际来源拒绝读取，不因消费 Agent 的共享标识或同租户目录嵌套公开私有内容

#### Scenario: 同租户成员以绝对路径读取他人私有 Agent 文件

- **WHEN** 普通成员（非 `tenant_admin`、非该 Agent 属主）以绝对路径请求同租户内他人私有 Agent workspace 中的文件，无论请求声明的 Agent 参数是否为共享 Agent
- **THEN** 系统按不可见拒绝（403 或 404），不返回文件内容或路径存在性

#### Scenario: 目录嵌套不公开私有 Agent 内容

- **WHEN** 普通成员（非 `tenant_admin`、非该 Agent 属主）以相对路径请求、或列举一个位于本租户共享根之下的他人私有 Agent workspace
- **THEN** 系统拒绝读取并在列举中省略该 Agent，不因「嵌套在共享根内」公开其内容或路径存在性

#### Scenario: 私有 Agent 的属主与租户管理员仍可读取

- **WHEN** 私有 Agent 的属主本人，或同租户的 `tenant_admin`，以绝对路径请求该私有 Agent workspace 中的文件
- **THEN** 系统返回内容，归属校验不阻止合法读取

#### Scenario: 归属无法唯一确定时失败关闭

- **WHEN** 被请求路径同时落在同租户两个不同 Agent 的 workspace 之下，或无法解析出唯一归属
- **THEN** 系统按不可见拒绝，不任选其一的 Agent 归属放行
