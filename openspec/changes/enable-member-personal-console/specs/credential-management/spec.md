## MODIFIED Requirements

### Requirement: 凭据按租户与资源授权

凭据 SHALL 归属明确租户，并绑定具体资源或用途；个人凭据还 SHALL 明确属于该租户内的 owner。使用时 MUST 验证当前调用者、有效租户成员、目标资源及用途授权；个人凭据必须同时匹配本人所有权，owner 可在允许的个人配置入口维护其版本而无需管理员代办。持有个人凭据 MUST NOT 授予未获权工具、模型或技能的执行资格。

跨租户复用、跨用户使用个人凭据、借管理员身份代用和未获准用途注入 SHALL 被拒绝。所有者及管理员的读取投影均只给掩码，MUST NOT 经管理 API 回显明文，私有凭据不因平台 all 或治理资格变成公共凭据。

#### Scenario: 跨租户使用凭据被拒绝
- **WHEN** A 租户的任务尝试使用 B 租户登记的凭据
- **THEN** 使用前拒绝，不注入该凭据

#### Scenario: 未获准角色读取凭据
- **WHEN** 既非个人凭据 owner、也未获得目标凭据用途授权的成员请求读取或使用凭据
- **THEN** 系统返回 403，不返回凭据内容

#### Scenario: 所有者维护本人渠道凭据

- **WHEN** 成员经允许的个人入口保存或轮换本人当前租户渠道凭据
- **THEN** 按本人归属和用途更新密文版本并记录脱敏审计，不需要授予公共凭据管理权限

#### Scenario: 管理员尝试使用成员个人凭据

- **WHEN** 非 owner 管理员为其任务指定成员个人凭据
- **THEN** 注入被拒绝，管理资格、平台 all 或相同租户不能代替本人匹配
